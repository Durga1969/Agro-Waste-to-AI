# Agro-Waste-to-AI
### Transforming Agricultural Waste into Smart Resources for a Sustainable Circular Economy

## Project Overview
Agro-Waste-to-AI is an AI-powered system designed to identify agricultural waste and suggest useful ways to convert it into valuable resources.

## Objectives
- Identify agricultural waste using AI.
- Classify different types of agricultural waste.
- Suggest suitable recycling and reuse methods.
- Promote sustainable waste management.

## Technologies Used
- Python
- Flask
- Machine Learning
- HTML, CSS, JavaScript

## Project Structure
- `app.py` – Main application
- `static/` – Static files
- `templates/` – HTML templates
- `labels.txt` – Classification labels
- `requirements.txt` – Project dependencies

## Applications
- Compost production
- Biogas production
- Animal feed
- Eco-friendly paper production

## Team Project
Developed as an academic project to promote agricultural sustainability and circular economy practices.
